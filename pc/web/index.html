Étapes de montage

  1. Pattes : imprime et assemble les 6 pattes en suivant le guide de hexapod-v2-7697, sans visser les palonniers pour l'instant.
  2. Électronique : ESP32 GPIO21 → SDA, GPIO22 → SCL, 3V3 → VCC, GND → GND des deux PCA9685. Sur la 2ᵉ carte (milieu droite et pattes arrière), ferme le pont A0 (adresse 0x41).
  3. Alimentation : les servos sur une alimentation 5-6 V séparée (plusieurs ampères) branchée au bornier V+ des PCA9685, masses communes avec l'ESP32.
  4. Servos : branche chaque servo sur son canal (tableau ci-dessous et étiquettes sur le modèle 3D), fil marron/noir côté GND.
  5. Vérifie chaque servo avec Tester : seul celui-là doit bouger.
  6. Palonniers : clique sur Pose de montage, puis visse les palonniers pour que chaque patte ait la pose du modèle 3D : fémur à plat, tibia vertical.
  7. Termine par l'onglet Calibration pour les réglages fins.

Choisir le servo

Comment faire

  1. Pose le robot sur une boîte, pattes dans le vide.
  2. Pose de calibration : coxa perpendiculaire au corps, fémur à plat, tibia vertical.
  3. Tester ce servo : la vraie patte doit bouger dans le même sens que la 3D. Si elle part dans l'autre sens, clique sur Inverser le sens, puis refixe son palonnier dans la pose de calibration.
  4. Pour chaque servo, règle le trim jusqu'à ce que la patte réelle ait la pose du modèle 3D.
  5. Enregistrer : les réglages restent dans l'ESP32.
